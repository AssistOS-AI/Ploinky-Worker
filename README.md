# Ploinky Workers

Ploinky Workers is a single CLI and JavaScript library for deterministic, phased model tasks. The command is `pworker`. It manages an independent local proxy for remote and local model providers.

Start with the [illustrated overview](docs/index.html) for use cases and core concepts. See [PWORKER.md](PWORKER.md) for installation, configuration, the task format, batching, queueing, monitoring, and the API.

Run the test suite with `npm test`.
